# 📚 वर्णमाला (Hindi Varnamala & Barahkhadi)

एक आधुनिक, स्वच्छ और बाल-अनुकूल हिंदी पठन अभ्यास वेब ऐप्लिकेशन। इसमें स्वर, व्यंजन, बाराखड़ी, बिना मात्रा वाले शब्द एवं मात्रा-युक्त शब्द शामिल हैं।

🔗 **लाइव प्रोडक्शन लिंक:** [https://peeekaboo.vercel.app](https://peeekaboo.vercel.app)

---

## ✨ मुख्य विशेषताएँ (Features)
- 🎙️ **स्पष्ट भारतीय न्यूरल उच्चारण:** Microsoft Swara Neural आवाज़ के साथ स्टुडियो-ग्रेड ऑडियो (Zero Robotic Voice / Google TTS Blocker)।
- 🔤 **शुद्ध मात्रा पठन:** मात्राओं (`◌ि`, `◌ु`, `◌ा`, आदि) पर क्लिक करने पर केवल शुद्ध स्वर ध्वनि (`इ`, `उ`, `आ`) सुनाई देती है, कोई अनावश्यक वाक्य नहीं।
- 🎨 **स्वच्छ व आधुनिक UI:** Baloo 2 व Plus Jakarta Sans टाइपोग्राफी के साथ मिनिमल, डिस्ट्रैक्शन-फ्री और सुंदर फ़्लैशकार्ड इंटरफ़ेस।
- ⚡ **सर्वरलेस क्लाउड आर्किटेक्चर:** Vercel Python Serverless Function (`/api/tts`) + CDN ऑडियो कैसेट बैकएंड।
- 📱 **पूर्णतः रिस्पॉन्सिव:** मोबाइल, टैबलेट व डेस्कटॉप सभी पर सुचारू रूप से कार्य करता है।

---

## 🚀 लोकल पर चलाने के लिए (Run Locally)
1. रिपॉजिटरी क्लोन करें:
   ```bash
   git clone https://github.com/MsCoder50/hindi-varnamala.git
   cd hindi-varnamala
   ```
2. लोकल न्यूरल सर्वर चालू करें:
   ```bash
   pip install edge-tts
   python3 tts_server.py
   ```
3. `index.html` को किसी भी ब्राउज़र में खोलें।
